# agenteai-oracle
Agente de IA corporativo (RAG) que responde perguntas em linguagem natural com base exclusivamente em documentos internos aprovados, sempre citando as fontes. Ingestão de PDF, Word, Excel, PowerPoint, Markdown, CSV, JSON e HTML. Busca híbrida + reranking, orquestrado com LangGraph. API REST (FastAPI) + interface web (Streamlit).
